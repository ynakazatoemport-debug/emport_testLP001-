# images フォルダの使い方

このフォルダに、下記のファイル名で画像・動画を配置すると、サイト側は何も変更せずに自動で差し替わります
（`images/` を基準に相対パスで読み込んでいるため、フォルダごと運用しやすい構成にしています）。

ファイルが未配置の間は、各ページに部門カラーの斜めストライプ＋「写真：〇〇」というラベルが
仮表示されます（壊れた画像アイコンは出ません）。画像を置くと自動的にラベルは消え、写真に切り替わります。

## 命名ルール

`ページ名またはセクション名-用途.拡張子`（英語・小文字・ハイフン区切り）

同じ場所に複数カットを用意したい場合は末尾に2桁の連番を付けます（例：`creative-work01.jpg` `creative-work02.jpg`）。

## 必要な画像・動画一覧

### ロゴ（全ページ共通）
| ファイル名 | 用途 | 推奨比率／備考 |
|---|---|---|
| `logo.png` | ヘッダー（画面上部）のロゴ | 背景透過PNG推奨。高さ34px相当で表示されるので、横長すぎない比率が扱いやすい |
| `logo-white.png` | フッター（画面下部・濃い青の背景）用の白抜きロゴ | 背景透過PNG推奨。濃い背景でも読めるよう白系のロゴにしてください |

### トップページ（index.html）
| ファイル名 | 用途 | 推奨比率／備考 |
|---|---|---|
| `top-main-video.mp4` | ファーストビューの背景動画（PC作業・デザイン制作・調理・農作業・清掃・利用者とスタッフの関わりを短いカットでつないだループ映像） | 横長・16:9以上推奨。音声不要（muted再生）。ファイルが無い場合は下のポスター画像→ストライプ表示の順でフォールバック |
| `top-main-poster.jpg` | 上記動画の代替静止画（動画読み込み前・非対応環境向け） | 横長 |
| `top-departments-group.jpg` | 「4つの部門」セクションの写真（複数部門の作業風景コラージュなど） | 16:9 |
| `top-concept.jpg` | 「大切にしていること」導線セクションの写真（施設外観 or 相談風景） | 16:9 |

### エンポートについて（about.html）
| ファイル名 | 用途 |
|---|---|
| `about-philosophy.jpg` | 理念セクション（職員と利用者が話している様子） |
| `staff-photo01.jpg` | 大切にしていることセクション（スタッフの集合、または休憩中の様子） |
| `about-facility-creative.jpg` | 施設紹介：作業室（クリエイティブ） |
| `about-facility-agriculture.jpg` | 施設紹介：農場・栽培スペース |
| `about-facility-cooking.jpg` | 施設紹介：厨房・調理スペース |

### 部門紹介（departments.html）
| ファイル名 | 用途 |
|---|---|
| `creative-main.jpg` | クリエイティブ部門のメイン写真（PC作業・制作の様子） |
| `creative-work01.jpg`〜 | ［将来追加用］制作実績・成果物を掲載する際の画像（現在は未使用・構造のみ対応済み） |
| `agriculture-main.jpg` | 農業部門のメイン写真（農作業・収穫の様子） |
| `cooking-main.jpg` | キッチン部門のメイン写真（調理・盛り付けの様子／A型・B型共通） |
| `cooking-a-main.jpg` | ［任意］A型（キナリ佐々）だけの写真に差し替えたい場合 |
| `cooking-b-main.jpg` | ［任意］B型（エンポート伊万里）だけの写真に差し替えたい場合 |
| `cleaning-main.jpg` | 清掃部門のメイン写真（清掃作業・送迎の様子） |

> 献立紹介・活動記録などを将来追加する場合も、同じ命名ルール（例：`cooking-menu-2026-08.jpg`）で
> 追加していただければ、既存レイアウトを崩さず差し込めます。

## 画像を用意する際のポイント

- **比率が違っても崩れません**：各写真枠は縦横比を固定し、`object-fit: cover` で表示しているため、
  横長・縦長・正方形どれを入れても枠のサイズは変わりません。
- **サイズの目安**：横長（16:9）は幅1600px程度、正方形・縦長は幅1000〜1200px程度あれば十分です。
- **動画**：`top-main-video.mp4` は軽量化のため、10〜20秒程度のループ、5〜10MB以内を目安にしてください。
  透過レイヤー（明るいスクリム）を上に重ねる設計のため、動画自体は多少露出高め・コントラスト低めでも
  問題ありません。
