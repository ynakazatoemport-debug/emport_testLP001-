# 画像・動画 管理表

このフォルダに、下記のファイル名で画像・動画を配置すると、LPに自動的に反映されます（HTML/CSSの修正は不要です）。
ファイルが無い間は、カテゴリカラーの背景パターンとラベルが仮表示されます。

| ファイル名 | 用途 | 推奨比率・サイズ目安 |
|---|---|---|
| `top-main-video.mp4` | ファーストビュー背景動画（作業風景・手元・光の差し込む室内など、雰囲気重視のカット） | 16:9、1080p・30fps、10〜20秒ループ、H.264、5〜15MB程度 |
| `top-main-poster.jpg` | 上記動画の読み込み前ポスター画像／動画非対応環境のフォールバック | 1920×1080px 程度 |
| `about-philosophy.jpg` | 「エンポートとは」セクション：スタッフと利用者が話している様子 | 縦長 4:5、1200×1500px 程度 |
| `route-creative01.jpg` | クリエイティブ部門：PC作業・動画編集の様子 | 横長 16:11、1400×960px 程度 |
| `route-kitchen01.jpg` | 調理部門：厨房での調理・盛り付けの様子 | 横長 16:11、1400×960px 程度 |
| `route-agri01.jpg` | 農業部門：畑での栽培・収穫の様子 | 横長 16:11、1400×960px 程度 |
| `route-clean01.jpg` | 清掃部門：関係機関での清掃作業の様子 | 横長 16:11、1400×960px 程度 |

## 命名ルール（今後、写真を追加する場合）

`{セクション名}-{用途}-{連番}.拡張子` の形式に統一してください。例：

- 制作実績を追加する場合：`creative-work01.jpg` `creative-work02.jpg` …
- 月間献立を追加する場合：`kitchen-menu-2026-08.jpg` …
- 活動報告を追加する場合：`report-2026-08-01.jpg` …

## 動画を差し替える際の注意

- 音声は不要（`muted` 再生のため、音声トラックが無くても問題ありません）
- H.264（libx264）でエンコードし、`-movflags +faststart` を付けるとWeb上での再生開始が速くなります
- 例（ffmpeg）：
  ```
  ffmpeg -i input.mov -an -vcodec libx264 -crf 22 -movflags +faststart top-main-video.mp4
  ```
